## Internal Release Notes

**Version:** 1.2.4 (build 1)
**Platform:** iOS only
**Commits since v1.2.3:** 3 (1 iOS fix, 1 Android fix not shipped here, 1 tooling chore)
**Branch:** main

### Bug Fixes

- **Deleted alarms resurrected by sync (BUG-03)** — `CategoryDetailView.deleteAlarm` never called `deleteRemoteAlarm` and did not save the context, so the next `syncAlarms()` pulled the Firestore copy back. `CloudSyncService` now records pending remote deletions in UserDefaults before the Firestore delete and flushes them at the start of every sync, so an app kill between delete and confirmation cannot restore the alarm.

### Not in this build

- Android `AlarmReceiver` next-occurrence fix (commit 897e4ab, BUG-02) ships with the first Android release.

### What to Watch

- Plus users: delete, force-quit, relaunch, confirm the alarm stays gone on a second device.
