# Release v1.3.0

## What's New (App Store)

```
- Mark an alarm as done right from the Home Screen or Lock Screen widget, or ask Siri: "Mark rent as done in Chronir"
- Pick which alarm or category a widget tracks, such as "Car registration: 41 days"
- Add Chronir to Control Center and the Lock Screen to see your next alarm or create a new one
- Find your alarms in Spotlight search
- Focus filters: show only the categories you choose for each Focus. Hidden alarms still ring.
- Short one-time tips for snooze options, pre-alarm warnings and widgets
- Refined screens, paywall, settings and widgets for clearer, more consistent design
- Fixed an issue where alarms with Require Dismissal turned off did not ring
- Fixed an issue where snoozing from the Lock Screen did not ring again
- Fixed an issue where stopping an alarm from the Lock Screen did not record it as done
- Fixed an issue where an alarm you turned off could turn back on at launch for Chronir Plus members
```

## Promotional Text

```
Mark alarms done from widgets, Siri and Control Center, plus important alarm reliability fixes.
```

## Internal Release Notes

**Version:** 1.3.0 (build 1)
**Platform:** iOS only
**Branch:** sprint-surfaces (sprint-surfaces sprint + BUG-07 hotfix)

### Features
- **FEAT-06** Widget and Siri "Mark done" App Intents.
- **FEAT-07** Control Center and Lock Screen controls (Next alarm, New alarm).
- **FEAT-08** Spotlight indexing; result opens alarm detail.
- **FEAT-09** Configurable Next Alarm widget (alarm or category).
- **FEAT-10** Focus filters for list and widgets (display only).
- **FEAT-11** TipKit hints.
- **QA-05** Impeccable design audit fixes across screens, paywall, settings and widgets.

### Bug Fixes
- **BUG-07 (P0)** Non-persistent alarms were rejected by AlarmKit (countdown presentation with nil duration) and never rang, since v1.2.1. Also: duplicate registrations at fire; lock-screen Stop/Snooze now explicit LiveActivityIntents (snooze re-rings, stop logs completion); in-app firing screen no longer closes itself; system Done completes on Plus.
- **BUG-06** Plus users' disabled alarms re-enabled at launch.

### Not in this build
- Android changes on this branch (ANDROID-02, BUG-04, BUG-05, QA-05 Android) ship with the next Android release.
