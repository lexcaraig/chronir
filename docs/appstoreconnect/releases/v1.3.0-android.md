# Release v1.3.0 (Android)

First Google Play release. versionName 1.3.0, versionCode 2. Package `com.chronir.android`, Play app ID 4976022683312293991.

## Release notes (Play Console, en-US)

```
First release of Chronir for Android.
- Real alarms for long-cycle tasks: weekly, monthly, annual or one-time
- Full-screen, persistent alarms that keep ringing until you act
- Home screen widgets: see your next alarm, upcoming alarms, and mark one done in place
- Categories, snooze options and pre-alarm warnings
- Chronir Plus: unlimited alarms, custom snooze, photo attachments and completion history
```
