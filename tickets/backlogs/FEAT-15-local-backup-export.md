# FEAT-15: Local backup export / import

**Priority:** P2
**Category:** Feature
**Effort:** Medium
**Platform:** iOS, Android
**Status:** Open
**Sprint:** [sprint-surfaces](../sprints/sprint-surfaces.md)

---

## Goal
Any user, Free included, can export all their alarms to a file (Files app / Android share sheet) and import it on a new phone, so their data is safe without cloud backup.

## Notes
Council required: file format and versioning, import conflict handling (duplicates, the 3-alarm Free limit, keeping deleted alarms deleted per FB-02), photos, and tier positioning relative to Plus cloud backup.
